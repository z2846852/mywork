! 音高图说明

连续频率：以 MIDI 半音的对数纵轴显示实际频率（Hz），自第一次有效发声锁定纵轴；用上下按钮整体平移纵轴。曲线不因唱到调外音而变红。五线谱：五条线严格等距，按音名字母的级进排列，超出谱表使用局部加线；相同稳定音连续采样合并为一个音符，不推断真实乐谱时值。选择目标音后，才根据相对目标音的音分误差和容差标红；不设目标时只记谱，不判断对错。停声时数据保持，横轴为有效发声样本而非真实时间；对完整旋律评分尚需导入目标旋律。

示范音由 Android 英式英语 TTS 朗读整个例词，而非合成单个 IPA 音。ZIPA 会误识别短音；专项反馈只是候选音素比对，不是专业发音打分。不同口音的 IPA 写法会有差异。

! 模型能力与开源参考

安装 ZIPA 后，模型从真实 PCM 直接产生 IPA 音素。英语模式再利用独立的本地发音/英汉词典，对整个 IPA 序列反向检索单词；不先通过 ASR 猜单词。结果的百分比只表示音素序列匹配程度，不衡量你的口音好坏。

词典源：open-dict-data/ipa-dict（美式 IPA）及 skywind3000/ECDICT（英汉释义与词频）；构建时生成紧凑离线词库。专项练习的 44 音标使用传统英式 IPA 分类，示例词由系统英式 TTS 发声；此分类和本机美式词典、ZIPA 的音素标记并非完全一致。可参考 GitHub Nico-Sanchez/schwa 的交互设计，但没有复制其音频或代码。普通话模式仅保留模型输出的 IPA。
